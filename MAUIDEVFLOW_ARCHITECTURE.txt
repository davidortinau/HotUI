2. TREE WALKER INTERFACE DEPENDENCIES
──────────────────────────────────────

Application (Root)
    │
    └─ IVisualTreeElement.GetVisualChildren()     ◄── Primary Traversal Interface
         │
         ├─ Window
         │   └─ Page (has NavigationBar title, ToolbarItems)
         │       ├─ Shell                          (Flyout, Tabs)
         │       ├─ NavigationPage                 (Back Button)
         │       ├─ FlyoutPage                     (Flyout Toggle)
         │       ├─ TabbedPage                     (Tab Bar Items)
         │       └─ [VisualElement children]
         │           ├─ Label, Button, Entry...
         │           └─ [nested children]
         │
         └─ [Synthetic Elements] (NOT in IVisualTreeElement but injected)
             ├─ NavBarTitle
             ├─ BackButton
             ├─ ToolbarItem
             ├─ FlyoutButton, FlyoutItem
             ├─ ShellTab
             ├─ SearchHandler
             └─ TabbedPageTab


3. ID GENERATION STRATEGY
─────────────────────────

┌─ Element.Id (Guid.ToString("N")[..12])           ◄── Primary
├─ AutomationId (from VisualElement)               ◄── Preferred if present
└─ Platform stamp (EnsurePlatformStableId)         ◄── Fallback

Collision handling: suffix with truncated GUID or platform ID


4. NODE EXTRACTION: ElementInfo PROPERTIES
────────────────────────────────────────────

┌─ Identity
│  ├─ Id                  (stable ID)
│  ├─ ParentId
│  ├─ AutomationId
│  └─ Type/FullType       (element.GetType().Name/FullName)
│
├─ Visibility & State
│  ├─ IsVisible
│  ├─ IsEnabled
│  ├─ IsFocused
│  └─ Opacity
│
├─ Content
│  ├─ Text                (Label.Text, Button.Text, BaseShellItem.Title)
│  └─ Value               (Switch.IsToggled, Slider.Value, etc.)
│
├─ Positioning
│  ├─ Bounds              (Frame.X/Y/Width/Height - logical)
│  └─ WindowBounds        (Platform native absolute coords)
│
├─ Interaction
│  ├─ Gestures[]          ([tap, swipe, pan, drag, drop, pinch])
│  └─ StyleClass[]        (CSS classes)
│
├─ Platform Integration
│  ├─ NativeType          (Handler?.PlatformView?.GetType().FullName)
│  └─ NativeProperties{}  (Platform-specific data)
│
└─ Hierarchy
   └─ Children[]          (Recursive nested elements)


5. SYNTHETIC ELEMENTS ARCHITECTURE
───────────────────────────────────

Marker Types (inner classes in VisualTreeWalker):
  ├─ NavBarTitleMarker        { Title, Page }
  ├─ BackButtonMarker         { Navigation, Title }
  ├─ SearchHandlerMarker      { Handler }
  ├─ FlyoutButtonMarker       { Shell }           ☰ button
  ├─ ShellFlyoutItemMarker    { Item, Shell }
  ├─ ShellTabMarker           { Section, Shell }
  ├─ FlyoutToggleMarker       { FlyoutPage }
  └─ TabbedPageTabMarker      { Page, TabbedPage }

Injection Points in WalkElement():
  ├─ Page → ToolbarItems, NavBarTitle, BackButton, SearchHandler
  ├─ Shell → FlyoutButton, FlyoutItems, Tabs
  ├─ NavigationPage → NavBar title + back button
  ├─ FlyoutPage → Flyout toggle
  └─ TabbedPage → Tab bar

7. MAIN WALKER METHODS (PUBLIC API)
───────────────────────────────────

List<ElementInfo> WalkTree(Application app, int maxDepth = 0, int? windowIndex = null)
  └─ Returns: Full tree with hierarchy

ElementInfo? WalkElement(IVisualTreeElement element, string? parentId, int depth, int maxDepth)
  └─ Returns: Single element with children (recursive)

List<ElementInfo> Query(Application app, string? type, string? automationId, string? text)
  └─ Returns: Flat list (no children) matching criteria

List<ElementInfo> QueryCss(Application app, string selector)
  └─ Returns: CSS selector results (flat, via Fizzler)

object? GetElementById(string id, Application? app)
  └─ Returns: IVisualTreeElement or Marker object for interaction

string? GetIdForElement(IVisualTreeElement element)
  └─ Reverse lookup: ID from element

List<VisualElement> HitTestByBounds(double x, double y, Application app, int? windowIndex)
  └─ Returns: Elements at point


8. CSS SELECTOR SUPPORT
───────────────────────

CssSelectorEngine.Query(List<ElementInfo> tree, string selector)
  ├─ Uses Fizzler library for parsing
  ├─ ElementInfoOps implements IElementOps<ElementInfo>
  │   └─ Adapts CSS selectors to ElementInfo properties
  │
  └─ Supported selectors:
      ├─ Type: Button, Label, Entry
      ├─ Attribute: [automationId="foo"], [text*="search"]
      ├─ Class: .myStyleClass
      ├─ Pseudo-class: :visible, :hidden, :enabled, :disabled, :focused
      ├─ Combinators: > (child), (descendant), + (adjacent), ~ (sibling)
      └─ Custom MAUI: [__maui-visible], [__maui-focused]


9. PLATFORM IMPLEMENTATIONS
────────────────────────────

PlatformVisualTreeWalker (MauiDevFlow.Agent)
  ├─ iOS/Mac Catalyst:
  │   ├─ ResolveWindowBounds: UIView.ConvertRectToView()
  │   └─ PopulateNativeInfo: UIView accessibility, UIControl state
  │
  ├─ Android:
  │   ├─ ResolveWindowBounds: View.GetLocationOnScreen()
  │   └─ PopulateNativeInfo: View properties, clickable
  │
  ├─ Windows:
  │   ├─ ResolveWindowBounds: FrameworkElement bounds
  │   └─ PopulateNativeInfo: UIAutomation properties
  │
  └─ macOS:
      ├─ ResolveWindowBounds: NSView bounds
      └─ PopulateNativeInfo: NSControl state, accessibility

GtkVisualTreeWalker (MauiDevFlow.Agent.Gtk)
  ├─ ResolveWindowBounds: Widget.ComputeBounds()
  └─ PopulateNativeInfo: GTK widget properties

11. DEPENDENCY INJECTION INTEGRATION
─────────────────────────────────────

Current: MauiAppBuilder.AddMauiDevFlowAgent(...)
  └─ Registers PlatformAgentService in DI
  └─ Wires up lifecycle events
  └─ Creates HTTP server on port 8000+ (or broker-assigned)

For Comet: Override CreateTreeWalker()
  └─ PlatformAgentService subclass
  └─ Return CometAwareVisualTreeWalker
  └─ Add to DI container instead

13. MARKER TYPES REFERENCE
──────────────────────────

Each marker preserves reference to MAUI object for stable identity:
  NavBarTitleMarker       ← m.Page
  BackButtonMarker        ← m.Navigation (INavigation)
  SearchHandlerMarker     ← m.Handler (SearchHandler)
  FlyoutButtonMarker      ← m.Shell
  ShellFlyoutItemMarker   ← m.Item (ShellItem)
  ShellTabMarker          ← m.Section (ShellSection)
  FlyoutToggleMarker      ← m.FlyoutPage
  TabbedPageTabMarker     ← m.Page (Tab page)

GetSyntheticText() → Extracts display text from marker
GetSyntheticTypeName() → Returns display type name
BuildSyntheticElementInfo() → Creates ElementInfo for marker
